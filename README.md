# proit.top

Публичный сайт PROIT: маркетинговые страницы, услуги, кейсы и публичные материалы.

## Границы репозитория

В репозитории разрешены только:

- исходный код сайта;
- публичные тексты и изображения;
- публичная конфигурация сборки;
- документация по запуску и публикации без секретов.

Не добавлять:

- `.env` и токены;
- пароли, SSH-ключи и сертификаты;
- выгрузки клиентов и заявки;
- персональные данные;
- внутренние планы Hermes;
- непубличные договоры, счета и переписку;
- резервные копии и дампы баз данных.

## Локальная разработка

Команды будут добавлены после утверждения финального стека и создания Astro-проекта.

## Публикация

Целевое production-окружение: Netlify, домен `proit.top`.

До подключения домена и аналитики необходимо отдельно проверить:

- production-сборку;
- SEO: `title`, `description`, canonical, `robots.txt`, `sitemap.xml`;
- мобильную версию и доступность;
- производительность и 3D-fallback;
- формы и обработку заявок;
- отсутствие секретов в Git.
